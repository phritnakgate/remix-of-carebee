# คู่มือใช้งาน CareBee

CareBee ช่วยจัดตารางเตือนทานยา ดูประวัติ และเชื่อมต่อกล่องยา ESP32 เพื่อรับสถานะของกล่องและส่งการเตือนตามเวลา

## 1. เริ่มใช้งาน

1. เปิด [CareBee](https://carebee-copy.lovable.app/) แล้วกด **ดำเนินการต่อด้วย Google**
2. ไปที่ **รายการยา → เพิ่มยา** กรอกชื่อยา จำนวนเม็ดต่อครั้ง ช่วงเวลาที่ทาน และช่องในกล่อง แล้วกด **บันทึก**
3. เปิด **ตารางยารายสัปดาห์** เลือกวัน เวลา และ **เปิดเตือน** ให้รายการที่ต้องการส่งไปยังกล่อง
4. ดูรายการของวันนี้และยืนยันว่าทานยาแล้วได้จากหน้าหลัก ดูย้อนหลังได้ที่ **ประวัติการทานยา**

## 2. เชื่อมต่อกล่อง ESP32

1. ไปที่ **กล่องยา → เพิ่มกล่อง ESP32 จริง** ตั้งชื่อแล้วกด **บันทึก**
2. เก็บ **รหัสอุปกรณ์** ไว้ให้คนตั้งค่า ESP32 รหัสนี้แสดงครั้งเดียว ส่วนรหัสกล่องจะอยู่ท้าย topic ของกล่อง ใช้คัดลอก topic ทั้งบรรทัดจากหน้าตั้งค่าได้เลย
3. เปิด **การตั้งค่า ESP32 · MQTT** ใต้กล่องที่เพิ่ม กด **EMQX Public** หรือ **HiveMQ Public** ให้ตรงกับ broker ที่ตั้งใน ESP32 หรือ MQTTX

   | Broker | โฮสต์ทั้งสองฝั่ง | พอร์ต WSS ฝั่งเว็บ | พาธฝั่งเว็บ | พอร์ต TCP ฝั่ง ESP32 หรือ MQTTX Desktop |
   | --- | --- | --- | --- | --- |
   | EMQX Public | `broker.emqx.io` | `8084` | `/mqtt` | `1883` |
   | HiveMQ Public | `broker.hivemq.com` | `8884` | `/mqtt` | `1883` |

4. ให้ ESP32 **ส่ง** ข้อมูลไปยัง topic เซนเซอร์ และ **รอรับ** ข้อความจาก topic แจ้งเตือน ใช้ topic เต็มที่แสดงในหน้าของกล่อง เช่น `medicine/sensor/<รหัสกล่อง>` และ `medicine/schedule/<รหัสกล่อง>`
5. กด **เชื่อมต่อ** แล้วรอให้ขึ้น **เชื่อมต่อ Broker แล้ว** สีเขียว ถ้ากด **ตัดการเชื่อมต่อ** หรือการเชื่อมต่อหลุด ให้กด **เชื่อมต่อ** เองอีกครั้ง ถ้าปิดแท็บขณะยังเชื่อมอยู่ CareBee จะจำค่าและต่อให้อีกเมื่อกลับมาเปิดเว็บหลังล็อกอินในเบราว์เซอร์เดิม

> **ระหว่างใช้งาน** เปิดแท็บ CareBee ไว้และให้เครื่องทำงานอยู่ สลับหน้าใน CareBee ได้ ถ้าปิดแท็บหรือเครื่องหลับ เว็บอาจพลาดเวลาส่ง การสาธิตผ่าน broker สาธารณะควรใช้กล่องและรายการยาทดลอง เพราะผู้ใช้รายอื่นอาจอ่านหรือส่งข้อความบน topic สาธารณะได้

## 3. ดูข้อมูลขาเข้าและขาออก

เปิด **กล่องยา → การตั้งค่า ESP32 · MQTT → ข้อความ MQTT** ของกล่องที่ต้องการ แต่ละรายการแสดงเวลา topic และข้อมูลในข้อความ (payload)

| สิ่งที่เห็น | ความหมาย |
| --- | --- |
| **ขาเข้า จาก ESP32** มีรายการใหม่ | ข้อความผ่าน MQTT มาถึงเบราว์เซอร์แล้ว |
| **CareBee ประมวลผลแล้ว** | แอปตรวจสอบและประมวลผลข้อความเซนเซอร์หรือการยืนยันแล้ว |
| **ได้รับแล้ว แต่ประมวลผลไม่สำเร็จ** | ตรวจรหัสอุปกรณ์ รูปแบบข้อความ และการเชื่อมต่อกับเว็บ |
| **ข้อความค้างจาก broker · ข้าม** | เป็นข้อความที่ broker เก็บไว้จากก่อนหน้านี้ ให้ ESP32 ส่งข้อความใหม่โดยปิด `retain` |
| **ขาออก ไปยัง ESP32 · Broker ยืนยันแล้ว** | Broker รับข้อความเตือนแล้ว ให้ดูที่ ESP32 อีกครั้งว่ากล่องทำงานตามที่ตั้งไว้หรือยัง |

หน้าจอแสดง 30 ข้อความล่าสุดต่อฝั่งของแต่ละกล่องและซ่อนรหัสอุปกรณ์ ปุ่ม **ล้างประวัติข้อความ** ล้างเฉพาะรายการที่แสดงบนแท็บนี้ ประวัติการทานยายังอยู่ในเมนูเดิม

## 4. ทดสอบรับส่งด้วย MQTTX

ใช้กล่องทดลอง และเปิด **การตั้งค่า ESP32 · MQTT** ค้างไว้จนขึ้นสีเขียว

1. เปิด **MQTTX Desktop** แล้วเชื่อมโฮสต์เดียวกับที่ตั้งใน CareBee ด้วย MQTT/TCP พอร์ต `1883` ถ้าใช้ **MQTTX Web** ให้ใช้พอร์ต WSS และพาธตามตารางด้านบน ตั้ง **Auto Reconnect** ของ MQTTX เป็นปิดหากต้องการให้ MQTTX หยุดและรอคำสั่งเชื่อมต่อเองด้วย
2. **ทดสอบ CareBee → MQTTX** ใน CareBee กด **คัดลอก topic ขาออก** แล้วเพิ่มใน **New Subscription** ของ MQTTX จากนั้นใส่ JSON หรือข้อความในช่อง **ข้อมูลทดสอบ** ของ CareBee แล้วกด **ทดสอบ Publish** ข้อความควรปรากฏใน MQTTX และในกล่องขาออกของ CareBee
3. **ทดสอบ MQTTX → CareBee** กด **คัดลอก topic ขาเข้า** จาก CareBee แล้ววางในช่อง Publish ของ MQTTX ตั้ง QoS เป็น `1` ปิด **Retain** แล้วส่งตัวอย่างด้านล่าง กล่องขาเข้าของ CareBee จะแสดง **ทดสอบ** และ **ได้รับข้อความแล้ว** ตัวอย่างนี้ใช้ตรวจการรับส่งโดยไม่บันทึกสถานะอุปกรณ์หรือประวัติยา

```json
{"type":"carebee_test","message":"Hello from MQTTX"}
```

ถ้ายังไม่เห็นข้อความ ให้เทียบโฮสต์และ topic ทั้งบรรทัด รวมถึงรหัสกล่องท้าย topic ใน MQTTX ให้สร้าง subscription ขาออกก่อนกดส่ง และลองยกเลิกตัวกรองข้อความถ้าเลือก topic อื่นค้างอยู่ [คู่มือ MQTTX](https://mqttx.app/docs/get-started)

ถ้า CareBee แสดง `wss://broker.hivemq.com:8884/mqtt` ให้ MQTTX Desktop และ ESP32 ใช้ `broker.hivemq.com:1883` ด้วย ถ้าฝั่ง MQTTX ใช้ `broker.emqx.io:1883` ให้เลือก **EMQX Public** ใน CareBee ก่อนเชื่อมต่อ สีเขียวยืนยันว่าเว็บต่อ broker แล้ว ส่วนสถานะกล่อง ESP32 จะเปลี่ยนเมื่อ CareBee ได้รับรายงานที่ตรวจรหัสอุปกรณ์ผ่าน

## 5. ลองส่งแจ้งเตือนตามตารางหนึ่งรอบ

1. ให้กล่องส่งสถานะเซนเซอร์หนึ่งครั้ง แล้วดูว่ามีข้อความใหม่ใน **ขาเข้า**
2. สร้างรายการยาทดลอง เลือกช่องในกล่อง ตั้งเวลาอีกไม่กี่นาทีในวันนี้ และเปิดเตือน ตรวจว่ากล่องตั้งให้รับแจ้งเตือนของรายการนั้น
3. เปิด CareBee ทิ้งไว้ เมื่อถึงเวลาจะเห็นข้อความใน **ขาออก** ค่าปกติส่งรายละเอียดรอบยาเป็น JSON ถ้าเฟิร์มแวร์ต้องการคำสั่งเฉพาะ ให้กรอกที่ **ข้อมูลแจ้งเตือนที่กำหนดเอง**
4. เมื่อ broker ยืนยันข้อความแล้ว ให้ตรวจที่ ESP32 ว่ารับ topic เดียวกันและทำงานตามที่ตั้งไว้

ถ้าขึ้นสีเขียวแต่ยังไม่เห็น **ขาเข้า** ให้ตรวจว่า ESP32 ต่อ broker เดียวกับเว็บและส่งไปยัง topic เซนเซอร์แบบเต็ม ถ้าไม่เห็น **ขาออก** ให้ตรวจวัน เวลา เขตเวลาในหน้า **ตั้งค่า** ปุ่ม **เปิดเตือน** และสถานะของรอบยา แอปส่งเฉพาะรอบที่ถึงเวลาและยังไม่ได้ยืนยันว่าทานแล้ว
